Hi-Fi Prototype for Scheduler project

https://scheduler-1i4v.onrender.com 

To run this project locally: In the scheduler directory of this project, use the terminal to run npm install  
Then the project can be run using npm run dev OR npm run build and then npm run start  
Find the project at localhost:3000
